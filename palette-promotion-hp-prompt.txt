# Palette Promotion 会社HP作成プロンプト

## プロジェクト概要
Palette Promotion株式会社の公式ホームページを作成するNext.jsプロジェクトです。
既存のNiziIROぱれっとLPと同じ技術スタックとビルド設定を使用して統一感を保ちます。

## 技術仕様
- **フレームワーク**: Next.js 15.5.3
- **スタイリング**: Tailwind CSS
- **言語**: TypeScript
- **ビルド設定**: 静的エクスポート（output: "export"）
- **デプロイ先**: https://palette-promotion.com/（ルートディレクトリ）
- **画像最適化**: sharp ライブラリ使用

## 技術的な注意点

### Next.js設定
```typescript
// next.config.ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  output: "export",
  images: {
    unoptimized: true,
    remotePatterns: [],
  },
  trailingSlash: true,
  reactStrictMode: false,
  poweredByHeader: false,
  compress: true,
  // チャンクエラーを防ぐ設定
  webpack: (config) => {
    config.optimization.splitChunks = false;
    config.optimization.runtimeChunk = false;
    return config;
  },
};

export default nextConfig;
```

### デプロイ設定
- 静的エクスポート（outフォルダ）
- ルートディレクトリ（https://palette-promotion.com/）にデプロイ
- .htaccessファイルは不要（ルートデプロイのため）

## 開発手順

1. **プロジェクト初期化**
   ```bash
   npx create-next-app@latest palette-promotion-hp --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"
   ```

2. **依存関係インストール**
   ```bash
   npm install sharp react-icons
   ```

3. **設定ファイル更新**
   - next.config.tsを上記設定に更新
   - package.jsonを上記設定に更新

4. **コンポーネント作成**
   - 各セクション用のコンポーネントを作成
   - レスポンシブ対応を実装

5. **画像最適化**
   - 画像ファイルをpublicフォルダに配置
   - sharpを使用して画像最適化

6. **ビルド・デプロイ**
   ```bash
   npm run build
   ```
   - outフォルダの内容をサーバーのルートディレクトリにアップロード
